季度权限再认证跑完之后，超期没确认的权限全都留着，被撤的也只有一小部分：超期未确认的权限必须默认撤销；确认必须由权限所有者或上级完成；撤销必须覆盖该权限的全部实例；同一批次不得重复处理同一权限；每个批次必须有截止时间；结果必须可审计；批量处理时各批次必须相互独立。已确认集合与已撤销集合必须互斥，二者的并集必须覆盖全部权限；同一批次重复运行必须得到相同结果。
